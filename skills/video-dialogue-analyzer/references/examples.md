# 示例数据

## 示例 1：在线 + 唤醒（独立唤醒词，设备应答后下指令）

### 原始视频文件名

`demo_001.mp4`

### Whisper 识别出的完整对话

```
小度小度。
在呢。
打开客厅的灯。
好的，已经为你打开客厅的灯。
```

### 判断依据

- **net_type=在线**：无任何离线信号（未提示离线模式、未报网络异常），助手全程正常响应并正确理解指令，按「举证责任在离线一方」默认判在线。注意：开灯是本地控制，但**本地控制 ≠ 离线**，不能据此判离线
- **wake_type=唤醒**：独立唤醒词"小度小度"，设备应答"在呢"后用户再下指令
- **dialog_content**：提取用户具体指令"打开客厅的灯"

### AI 分析输出（步骤 3）

```json
{
  "net_type": "在线",
  "wake_type": "唤醒",
  "dialog_content": "打开客厅的灯"
}
```

### 重命名结果（步骤 4）

- 文件名格式：`net_type-wake_type-dialog_content`
- 拼接后：`在线-唤醒-打开客厅的灯`
- 最终文件名：`在线-唤醒-打开客厅的灯.mp4`

### Excel 行

| 原文件名         | 完整对话                          | 离线/在线 | 唤醒类型 | 具体指令   | 新文件名             | 处理状态 |
| ------------ | ----------------------------- | ----- | ---- | ------ | ---------------- | ---- |
| demo_001.mp4 | 小度小度。在呢。打开客厅的灯。好的，已经为你打开客厅的灯。 | 在线    | 唤醒   | 打开客厅的灯 | 在线-唤醒-打开客厅的灯.mp4 | 处理成功 |

## 示例 6：重名冲突处理

假设文件夹中已存在 `在线-唤醒-打开客厅的灯.mp4`，新视频处理后生成的文件名与之相同：

1. 首次生成：`在线-唤醒-打开客厅的灯.mp4` → 已存在
2. 追加后缀：`在线-唤醒-打开客厅的灯_1.mp4` → 若仍存在则继续
3. 最终使用：`在线-唤醒-打开客厅的灯_2.mp4`
